# sBitx Documentation

Welcome to the sBitx documentation site for the 64-bit Raspberry Pi image and application.

sBitx is an improved version of the sBitx application designed for sBitx hardware, with active contributions from the amateur radio community.

## What you'll find here

- Setup and upgrade quick-start information
- Control and hardware reference guides
- Links to existing PDF/ODT reference documents while they are migrated
- Project release notes
